# PDF 双语对照 · 浏览器扩展

读英文 PDF 时，左边原页面、右边逐段中文——不用再来回切窗口往翻译软件里贴。

装上之后点一下工具栏图标，当前 PDF 会在新标签页里打开：左栏是原页渲染（版式、图、公式都在），
右栏是英文原文段落，每段后面紧跟着它的中文译文，两栏随滚动联动。

- **逐段对照，不是整篇机翻**：译文紧贴对应段落，读完英文抬眼看中文，不用找位置
- **原页不丢**：需要看公式细节、图表、排版时，左边随时能看
- **用自己的 API**：DeepSeek / OpenAI / 通义 / Kimi / OpenRouter / 本地 Ollama，任何 OpenAI 兼容接口都行
- **译文缓存在本机**：同一段只翻一次，关掉重开不用再花钱、不用再等
- **网页内嵌的 PDF 也能翻**：就是浏览器自己弹出 PDF 工具栏那种页面

## 安装

还没上架商店，手动加载一次即可（Edge / Chrome 通用）。

1. 拿到代码，二选一：
   - `git clone https://github.com/zeyuwang-neuro/pdf-bilingual.git`
   - 或[下载 ZIP](https://github.com/zeyuwang-neuro/pdf-bilingual/archive/refs/heads/main.zip) 解压到任意目录
2. 地址栏打开 `edge://extensions`（Chrome 是 `chrome://extensions`）
3. 打开左下角「开发人员模式」
4. 点「加载解压缩的扩展」，选中**含 `manifest.json` 的那层目录**
5. 装好会自动弹出设置页：填 API Key → 点「测试连接」→ 连上就能用了

## 用法

| 你想干的事 | 怎么做 |
|:--|:--|
| 翻译一个 PDF | 打开 PDF → 点工具栏上的扩展图标 |
| 翻译网页里内嵌的 PDF | 在那个页面上直接点扩展图标；会自动找到页面里真正的那个 PDF |
| 快捷键 | `Alt+Shift+T`（可在 `edge://extensions/shortcuts` 改成别的） |
| 翻译本机文件 | 把 `.pdf` 拖进阅读器窗口 |
| 某页译文不满意 | 点「重译本页」——忽略缓存重翻当前这一页 |
| 屏幕窄、想要单栏 | 点「单栏 / 双栏」切换 |
| 改 API 设置 | 点「设置」 |

窗口底部会显示进度（`已译 12/14 段`）。手动滚左栏时会暂停跟随，滚回右栏自动恢复。

## 设置

| 字段 | 怎么填 |
|:--|:--|
| 接口地址 | 填到 `/v1` 为止，程序自动补 `/chat/completions`。DeepSeek 就是 `https://api.deepseek.com/v1` |
| API Key | 你的密钥，只存在本机浏览器存储里，明文，不外传 |
| 模型 | 默认 `deepseek-chat`。换成你账号下可用的任意模型名即可 |

任何 OpenAI 兼容端点都能用。少数端点不支持 `response_format` 参数，程序会自动去掉重试，不用管。

## 隐私：东西会发到哪

- **PDF 的段落文字会发给你自己填的那个接口**，因为你请它做翻译。除此之外不发任何地方。
- **API Key 存在本机的扩展存储（`chrome.storage.local`）里，明文**。它只用于给你填的接口发请求。
- 扩展**不收集浏览记录、不做统计、不发遥测**。除了那个 LLM 接口，没有别的出站请求。
- 译文缓存在本机，卸载扩展或清浏览器数据就没了。

安装时 Edge 会提示「读取和更改你在所有网站上的数据」——因为扩展要能在任意 PDF 地址上取文件，
这属于加载本地扩展的固有权限，不是在做别的事。

## 适合什么，不适合什么

**适合**：双栏排版的论文、英文技术文档、职位广告、说明书、报告——只要有文本层就能翻。

**不适合**（都是这一版的设计边界，不是 bug）：

- **扫描件**：纯图片、没有文本层的 PDF 提不出字，本版不做 OCR
- **公式和表格**：公式会被拆成碎片，表格会被拍平成文本流；需要精确版式请看左栏原页
- **中文不会压在原版面上**：学术 PDF 里中文比英文短三到四成，硬塞会留大片空白，
  所以走的是「左右对照」而不是「覆盖原文」
- 需要登录的 PDF 会用当前会话的 cookie 取文件，多数能行；取不到就下载下来拖进窗口
- 窗口宽度变化后左栏是按比例缩放，不会重新按新宽度渲染（清晰度优先）

## 常见问题

**点了图标提示「这不是 PDF」**
当前页确实不是 PDF，或页面里的 PDF 是浏览器内存里的 blob（拿不到文件）。
在那个页面点下载，再把文件拖进阅读器窗口。

**提示「把 PDF 拖进来」**
同上：页面里没找到能直接取文件的 PDF。下载后拖进来即可。

**翻译一直失败 / 提示 401、403**
401 = Key 填错或已失效，回设置页重填并点「测试连接」。
403 = 端点不给访问（额度、地区、模型权限），换模型或换端点试试。

**某几段显示「翻译失败」**
单批请求失败时程序会自动降级为逐段重试，个别段落仍失败就只影响那几段。点「重译本页」可重来。

**换了模型，旧译文还在**
不会。缓存按「模型 + 提示词版本 + 段落原文」区分，换模型等于换缓存，所有段落会重新翻。

**快捷键没反应**
`Alt+Shift+T` 可能被别的扩展或系统占用了，去 `edge://extensions/shortcuts` 换一个。

**更新代码后行为没变**
改过 `manifest.json` 的权限时，「重新加载」在 Edge 上不可靠：看起来还在，但新权限没生效。
先「移除」扩展，再「加载解压缩的扩展」选同一个目录。

**翻一本 200 页的书要花多少钱**
取决于你用的服务商和模型单价，本项目不做估算也不会代你调用任何接口。可以确定的是：
同一段只计费一次（缓存命中不再请求），失败会自动降级而不是整批重发。
